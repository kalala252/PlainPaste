# PlainPaste

⌥⌘V でクリップボードの内容を書式なしのプレーンテキストとして貼り付ける、macOS 用のメニューバー常駐アプリです。

Web ページや Word からコピーしたテキストをそのまま貼り付けると、フォントや色などの書式が引き継がれてしまいます。macOS 標準の「ペーストしてスタイルを合わせる」⇧⌥⌘V はショートカットや挙動がアプリごとに異なり、対応していないアプリもあります。PlainPaste は、どのアプリでも同じショートカットで書式なしの貼り付けを行えるようにします。


## 機能

- 全アプリ共通のグローバルショートカット ⌥⌘V
- メニューバー常駐。Dock には表示されません
- 貼り付け後、書式や画像を含む元のクリップボードを自動で復元
- プレーン文字列を持たない RTF / HTML のみのクリップボードからもテキストを抽出
- 外部ライブラリ不使用

## インストール

現在はソースからのビルドのみに対応しています。動作には macOS 13 以降、ビルドには Swift 5.10 以降が必要です。Xcode 本体は不要で、Xcode Command Line Tools のみでビルドできます。

```bash
git clone https://github.com/kalala252/PlainPaste.git
cd PlainPaste
./Scripts/build-app.sh
open build/PlainPaste.app
```

初回起動時にアクセシビリティ権限を求められます。これは合成した ⌘V キーイベントの送信に必要なものです。システム設定 → プライバシーとセキュリティ → アクセシビリティで PlainPaste を有効にしてください。ホットキーの検知自体に権限は必要ありません。

## 使い方

テキストをコピーし、貼り付けたい場所で ⌥⌘V を押します。書式なしのテキストが貼り付けられ、クリップボードは元の内容に復元されます。

## 仕組み

1. Carbon の `RegisterEventHotKey` で ⌥⌘V を捕捉する
2. ペーストボードの全アイテムを型ごとの生データとして退避する
3. プレーンテキストのみを書き込み、`CGEvent` で ⌘V を合成して最前面のアプリに送信する。アクセシビリティ権限が必要なのはこの送信のみ
4. 300ms 後に退避した内容を復元する

| パス | 役割 |
|---|---|
| `Sources/PlainPasteCore/` | ペーストボード操作のコアロジック。ユニットテストの対象 |
| `Sources/PlainPaste/` | アプリ本体。メニューバー UI、ホットキー登録、ペースト実行 |
| `Tests/PlainPasteCoreTests/` | コアロジックのユニットテスト |
| `Scripts/build-app.sh` | `.app` バンドルのビルドスクリプト |
