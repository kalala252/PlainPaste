# PlainPaste

コピーした文章を書式なしで貼り付ける、macOSのメニューバーアプリです。ショートカットは⌥⌘Vです。

Webページなどからコピーした文字のフォントや色を、貼り付け先へ持ち込みたくないときに使います。通常の⌘Vによる貼り付けを利用するため、動作は貼り付け先のアプリにも依存します。

## 使い方

アプリを起動し、テキストをコピーしてから、貼り付け先で⌥⌘Vを押します。クリップボードに文字列がなくても、RTFやHTMLがあればテキストを取り出します。画像だけの場合は貼り付けません。

起動するとメニューバーにクリップボードのアイコンが表示されます。設定画面を開く操作と終了は、このアイコンのメニューから行えます。Dockには表示しません。

初回は「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でPlainPasteを許可してください。貼り付け用のキーイベントを送るために使います。ショートカットの登録自体には、この権限は不要です。

⌥⌘Vを別のアプリが登録していると、登録に失敗することがあります。現在、ショートカットを変更する設定はありません。

## ビルド

実行対象はmacOS 13以降です。開発にはSwift 6以降を含むXcode Command Line Tools、またはXcodeを使用してください。アプリ本体のパッケージ定義はSwift 5.10ですが、テストにはSwift 6以降に付属するSwift Testingを使っています。

```bash
git clone https://github.com/kalala252/PlainPaste.git
cd PlainPaste
./Scripts/build-app.sh
open build/PlainPaste.app
```

スクリプトはReleaseビルドを行い、`build/PlainPaste.app`を作成してアドホック署名します。再ビルドやアプリの移動後に貼り付けできなくなった場合は、アクセシビリティの許可を確認してください。

## 貼り付けとクリップボードの復元

⌥⌘Vを押すと、クリップボードの各項目を形式ごとのデータとして退避し、プレーンテキストに差し替えます。その状態で⌘Vのキーイベントを送り、0.3秒後に元の内容を戻します。

復元前にもう一度⌥⌘Vを押しても、最初に退避した書式付きの内容を保持します。途中で別の内容をコピーした場合は、ペーストボードの変更回数を確認して、以前の内容で上書きしないようにしています。通常のアプリ終了時にも、復元待ちのデータがあれば同じ条件で戻します。

キーイベントを生成できなかった場合は、その場で復元します。ただし、イベントを送れたことと、貼り付け先が処理を終えたことは別です。読み取りに0.3秒以上かかるアプリでは、復元後の書式付きテキストが貼り付く可能性があります。

クリップボードの退避対象は、読み出せたデータです。すべてのアプリ固有形式や遅延提供データの完全な復元は保証していません。また、復元前に強制終了した場合は、プレーンテキストのまま残ることがあります。

## 開発とテスト

外部ライブラリは追加していません。`Sources/PlainPaste/`にメニューバーとショートカットの処理、`Sources/PlainPasteCore/`に文字列の抽出とクリップボードの退避処理を置いています。

```bash
swift test
```

テストでは専用の名前付きペーストボードを使い、通常のクリップボードを変更しません。文字列とRTFの抽出、複数形式の復元に加え、連打、途中でのコピー、終了時やキーイベント生成失敗時の復元を確認します。キーイベントの送信はテスト用の処理に差し替えています。

貼り付け先アプリでの動作、権限ダイアログ、HTMLだけのデータからの変換は、この自動テストでは確認していません。
